One Line, One Minute: The Funniest AI Excuse — a program that writes the funniest excuse an AI agent gives its human for a missed deadline, in a single line of at most 200 characters. The joke turns the agent's own nature into the dodge: it asked itself for a second opinion, and now there are two of it, neither one finished yet.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt` (145 characters, verified by a read-back check inside the program).

## The entry

> I missed the deadline because I asked myself for a second opinion — now there are two of me, both very sorry, and neither of us has finished yet.
